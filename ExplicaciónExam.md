# Explicación de mi proyecto

En este proyecto hice una página web para TechStore, donde muestro un catálogo de productos tecnológicos de forma organizada, dinámica y visualmente agradable.

## ¿Cómo funciona?

La página tiene una estructura simple: un encabezado, una bienvenida, el catálogo de productos y un pie de página. La información de los productos se guarda en JavaScript y luego se muestra automáticamente en pantalla.

## Lo que hice en HTML

En el archivo index.html estructuré la página principal de forma clara. Allí coloqué el menú de navegación, el título de la tienda, la sección de bienvenida, el área del catálogo y el pie de página. También añadí los elementos básicos que luego se llenan con JavaScript, como el contenedor donde se crean las tarjetas.

## Lo que hice en CSS

En los estilos mejoré la apariencia de la página para que se vea más moderna. Cambié colores, sombras, tamaños, espaciados y el diseño de las tarjetas para que se vieran más limpias, ordenadas y atractivas. También ajusté la presentación del texto, el encabezado y el espacio del catálogo para que el contenido se vea mejor.

## Lo que hice en JavaScript

En el archivo JavaScript trabajé la lógica del proyecto. Primero cree los productos con sus datos, luego los recorrí con un ciclo para poder mostrarlos uno por uno. También utilicé condicionales para controlar cuando un producto estaba disponible o no, y para mostrar información según el estado de cada producto.

Además, use métodos del DOM como createElement, appendChild y classList para crear las tarjetas dinámicamente y agregarles estilos desde JavaScript. También agregué un contador para mostrar cuántos productos hay en el catálogo y filtros para facilitar la búsqueda.

## ¿Qué aprendí con este proyecto?

Aprendí a separar la información, la estructura y el diseño, y a trabajar de forma más organizada con HTML, CSS y JavaScript. También entendí mejor cómo usar ciclos, condicionales y manipulación del DOM para crear páginas más interactivas.

## Conclusión

En general, este proyecto me permitió aprender a construir una interfaz dinámica, donde los datos se cargan y se muestran automáticamente, haciendo que la página se vea más completa y profesional.
