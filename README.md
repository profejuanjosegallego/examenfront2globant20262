# TechStore

TechStore es una tienda virtual de productos tecnológicos desarrollada con HTML, CSS y JavaScript. El catálogo consume un archivo JSON con los productos y permite visualizar, filtrar y buscar artículos desde la interfaz.

## Funcionalidades

- Mostrar productos cargados desde un archivo JSON.
- Renderizar tarjetas dinámicas con nombre, precio, stock, marca y proveedor.
- Filtrar productos por disponibilidad.
- Buscar productos por nombre o categoría.
- Agregar, editar y eliminar productos desde la interfaz.

## Estructura del proyecto

- index.html: estructura principal de la página.
- assets/styles/index.css: estilos del sitio.
- assets/js/app.js: lógica del catálogo y filtros.
- assets/data/productos.json: datos de los productos.
- assets/imgs/logo.png: imagen del logo.

## Cómo ejecutar

1. Abre la carpeta del proyecto en tu navegador.
2. Ejecuta el archivo index.html directamente o sirve la carpeta con un servidor local.

Ejemplo con Live Server:

- Abre la carpeta en VS Code.
- Haz clic derecho en index.html y selecciona "Open with Live Server".

## Notas

El proyecto está pensado como una práctica de frontend con manipulación dinámica del DOM y consumo de datos JSON.
