# Cómo se construyó este proyecto

Este proyecto fue creado para mostrar un catálogo de productos tecnológicos de forma dinámica.

## Tecnologías usadas
- HTML para la estructura de la página
- CSS para el diseño y la presentación
- JavaScript para cargar y mostrar los productos

## Estructura del proyecto
- index.html: contiene la estructura principal
- css/styles.css: define los estilos visuales
- js/app.js: maneja la lógica del catálogo
- data/productos.js: guarda los productos en formato de JavaScript


## Pasos de construcción
1. Se creó la estructura básica de la página en HTML.
2. Se diseñó el diseño con CSS para que se vea limpio y organizado.
3. Se agregaron los productos en el archivo de datos.
4. Se escribió JavaScript para recorrer los productos y mostrarlos en pantalla.
5. Se agregó una interacción para que el usuario pueda ver y navegar el catálogo.
6. Se probó la página en el navegador para verificar que funcionara correctamente.

## Resultado
La página muestra los productos de manera dinámica, organizada y fácil de visualizar.

## Cómo abrirlo
Solo abre el archivo index.html en tu navegador.
